# PFS — Personal Financial Simulation

PFS 是一个轻量、开源的个人财务模拟工具，用于根据当前现金、负债和未来收支事件，预测未来的现金、负债与净资产变化。

## 版本
- 当前APP版本 v1.0.0;
- 当前数据版本 v1;

## 特点

- 单文件 HTML，打开即用
- 无需注册、无需服务器
- 数据默认保存在浏览器本地
- 支持收入、支出、借款、还债
- 支持单次及每日 / 每周 / 每月 / 每年循环事件
- 支持现金、负债、净资产预测
- 支持多版本情景模拟
- 支持中文、English、日本語
- 支持导出含数据或空白 HTML
- 支持 PFS 元数据编辑，可配合 AI 生成数据

## 使用

在线访问：

https://yuyaoyong.github.io

也可以直接下载 `index.html`，在浏览器中本地打开使用。

> 建议在电脑或平板等大屏设备上使用，以获得更完整的编辑与图表体验。

## 数据与隐私

PFS 不需要后端服务。财务数据默认仅保存在当前浏览器的本地存储中。

如需备份、迁移或分享，可通过页面内的导出功能生成包含数据的单文件 HTML。
